# مزاج — مرحلة الألعاب النارية

مشروع Vite + TypeScript + PixiJS لمرحلة الألعاب النارية.

## التشغيل

```bash
npm install
npm run dev
```

انقر في أي مكان على الشاشة لإطلاق لعبة نارية نحو نقطة النقر، بالإضافة إلى إطلاق تلقائي دوري.

## البنية

- `src/main.ts` — تهيئة تطبيق Pixi، القماش المتجاوب، خلفية النجوم، والتقاط النقر.
- `src/fireworks/Rocket.ts` — الصاروخ الصاعد الذي ينفجر عند ذروته.
- `src/fireworks/Particle.ts` — جسيم الانفجار/الأثر (جاذبية، احتكاك هوائي، تلاشي).
- `src/fireworks/FireworksSystem.ts` — إدارة الصواريخ والجسيمات والإطلاق التلقائي.
- `src/fireworks/colors.ts` — لوحات ألوان متناسقة لكل انفجار.
- `src/fireworks/textures.ts` — نسيج دائري ناعم مشترك بين كل الجسيمات.
