# ملفات الصوت

ضع ملفات الصوت هنا بهذه الأسماء بالضبط ليعمل الصوت تلقائيًا بدون أي تعديل بالكود:

| الملف | يُشغَّل عند |
|---|---|
| `reveal.mp3` | تكشّف العبارة بالدخان/اللهب |
| `launch.mp3` | إطلاق كل صاروخ |
| `explosion.mp3` | انفجار كل لعبة نارية |

إلى أن تُضاف الملفات، التطبيق يعمل بصمت تام (بدون أخطاء) وسيُسجَّل الفيديو بمسار صوتي فارغ فقط.
