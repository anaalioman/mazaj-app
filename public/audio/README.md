# ملفات الصوت

ضع ملفات الصوت هنا بهذه الأسماء بالضبط ليعمل الصوت تلقائيًا بدون أي تعديل بالكود:

| الملف | يُشغَّل عند |
|---|---|
| `reveal.mp3` | تكشّف العبارة بالدخان/اللهب |
| `launch.mp3` | إطلاق كل صاروخ (الصوت الأساسي) |
| `gearpile-explosion-3-386885.mp3` | تنويع عشوائي لصوت الإطلاق |
| `explosion.mp3` | انفجار كل لعبة نارية (الصوت الرئيسي) |
| `brvhrtz-boom-03-279195.mp3` | انفجار أخف يُستخدم للشحنات البعيدة عن المنتصف أفقيًا |
| `67213_cracklr-spark_1.mp3` / `29367_freesound_community-firework-s_1.mp3` | طرطشة/كراكل خفيفة تُشغَّل بعد كل انفجار (اختيار عشوائي بينهما) |
